# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues. Use GitHub's
private reporting instead: **Security → Report a vulnerability** on this
repository.

This includes anything that makes the server run a program, or read or
write files, in a way the user did not expect. For example, through
`compile_commands.json`, `.riscv-asm-lsp.yaml` or `#include` paths in an
untrusted folder.

## Supported versions

Only the latest release receives fixes.
