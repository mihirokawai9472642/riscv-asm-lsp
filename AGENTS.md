# AGENTS.md

Instructions for coding agents. The project's rules are written for people in
these documents; follow them:

- [README.md](README.md): what the project is, and how to install it.
- [CONTRIBUTING.md](CONTRIBUTING.md): the development container, checks, tests,
  code and data rules, pull requests and commits.
- [docs/architecture.md](docs/architecture.md): structure, code map and the
  rules that hold across the code. Read it before changing behaviour.
- [docs/configuration.md](docs/configuration.md),
  [docs/features.md](docs/features.md),
  [docs/editors.md](docs/editors.md) and [docs/data.md](docs/data.md):
  settings, feature behaviour, editor setup and the generated data.

In addition:

- Push a branch or open a pull request only when the user asks.
- If a change would alter a decision described in `docs/architecture.md`, ask
  first.
